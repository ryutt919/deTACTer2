# 시퀀스 데이터 클러스터링 방법론 요약

공의 이동 궤적과 같은 시퀀스 데이터를 분석하기 위한 5가지 주요 클러스터링 방법론을 정리합니다.

| 방법론 | 핵심 특징 | 추천 근거 |
| :--- | :--- | :--- |
| **TRACLUS** | 궤적을 선분 단위로 분할하여 클러스터링 | 가변 길이 해결 및 "직선의 조합" 데이터에 최적 |
| **LCSS** | 가장 긴 공통 부분 수열 탐색 | 노이즈와 아웃라이어에 대해 매우 높은 강건성 |
| **EDR** | 편집 거리(Edit Distance) 기반 유사도 측정 | 궤적의 위상학적 변화를 정밀하게 반영 |
| **Geometric + DBSCAN** | 기하학적 특징(방향, 거리 등) 벡터화 후 밀도 기반 군집화 | 대규모 데이터에서 압도적인 계산 효율성 |
| **Seq2Seq Embedding** | 신경망 기반 잠재 벡터 추출 후 군집화 | 복잡하고 비선형적인 전술적 의도 학습 가능 |
