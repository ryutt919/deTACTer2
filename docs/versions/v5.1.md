# deTACTer v5.1 Update Report

## 주요 변경 사항

### 1. VAEP 모델 평가 고도화: 브라이어 스코어(Brier Score) 도입

- 모델의 예측 확률값이 실제 결과와 얼마나 일치하는지 평가하는 **Brier Score** 산출 로직을 `compute_vaep.py`에 통합.
- **결과**:
  - Scores 모델 BS: `0.0031`
  - Concedes 모델 BS: `0.0005`
  - 0에 매우 가까운 값으로, 모델의 확률 보정 상태가 매우 우수함을 확인.

### 2. 순수 밀도 기반 클러스터링 (하드코딩 제거)

- 사용자의 피드백을 반영하여 `n_clusters=15`와 같은 인위적인 개수 지정을 삭제.
- **OPTICS**의 `xi(0.03)` 및 `min_samples(5)` 파라미터를 엄격하게 적용하여, 데이터 상에서 자연스럽게 발생하는 **고밀도 전술 패턴**만 추출.
- **결과**:
  - 총 138개 시퀀스 중 **2개의 핵심 전술 패턴** 자동 탐지.
  - 나머지 115개는 노이즈(-1)로 분류하여 분석의 정합성 확보.
