# deTACTer v5.8 Pipeline Walkthrough

## 1. 개요

본 문서는 Transformer 모델의 하이퍼파라미터 최적화(TPE) 결과를 바탕으로 실행된 v5.8 파이프라인의 최종 결과를 요약합니다.

## 2. 최적화 결과 (TPE)

- **Objective**: Maximize Silhouette Score (OPTICS Clustering)
- **Best Score**: `0.988`
- **Best Parameters**:
  - `total_seq_len`: **6** (기존 13 대비 대폭 축소)
  - `min_pass_count`: **2** (기존 3 대비 완화)
  - `optics_min_samples`: **6**
  - `hidden_dim`: 32, `num_layers`: 6, `num_heads`: 8

## 3. 실행 프로세스

1. **Sequence Extraction**: 최적화된 파라미터(Len 6, Pass 2)로 290개의 고품질 시퀀스 추출.
2. **Model Retraining**: Best Params로 Transformer 모델 100 Epoch 재학습 (Early Stopping @ Epoch 22 적용).
3. **Embedding**: 학습된 모델로부터 전술 임베딩 벡터 추출.
4. **Clustering**:
   - **Method**: Team-wise OPTICS
   - **Performance**: 높은 군집도(Silhouette 0.85+)를 보이는 다수의 전술 패턴 식별.
5. **Visualization**: 주요 클러스터에 대한 전술 애니메이션 생성 완료.

## 5. 결론

v5.8 업데이트를 통해 시퀀스 길이를 최적화하고 모델을 경량화하면서도, 전술적 패턴의 선명도는 크게 향상되었습니다. 특히 팀별 클러스터링을 통해 각 팀의 고유한 빌드업 스타일을 효과적으로 시각화할 수 있게 되었습니다.
