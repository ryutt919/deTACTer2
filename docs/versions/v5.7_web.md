# deTACTer Web Dashboard Walkthrough

deTACTer 프로젝트의 전술 분석 결과를 직관적으로 확인하고 공유할 수 있는 프리미엄 웹 대시보드 구현이 완료되었습니다.

## 🌟 주요 성과

### 1. 프리미엄 다크 모드 디자인 시스템

- **Visuals**: `index.css`를 통해 Glassmorphism, 네온 액센트, 부드러운 트랜지션이 적용된 현대적인 UI를 구축했습니다.
- **Typography**: `Outfit` 및 `Inter` 폰트를 사용하여 가독성과 고급스러움을 동시에 잡았습니다.

### 2. 역동적인 메인 페이지 (Home)

- **Hero Section**: "Football Reverse Engineered" 슬로건과 함께 프로젝트의 가치를 전달하는 애니메이션 섹션.
- **Explainers**: VAEP 및 유효 공격 시퀀스 추출 로직에 대한 명확한 시각적 설명을 포함합니다.

### 3. 고도화된 전술 분석 페이지 (Analysis)

- **Video Player**: 기존 파이프라인에서 생성된 mp4 전술 애니메이션을 웹에서 직접 재생 및 제어할 수 있습니다.
- **VAEP Timeline Chart**: `Recharts` 라이브러리를 사용하여 액션별 VAEP 기여도를 시계열 그래프로 시각화했습니다. 사용자의 요청대로 애니메이션 하단에 배치되었습니다.
- **Key Player Highlight**: 각 전술 시퀀스에서 가장 높은 VAEP 점수를 기록한 선수를 'MVP'로 자동 식별하여 상단에 강조 표시합니다.
- **Sidebar Stats**: 템포, 지속 시간, 이동 거리 등 정밀한 전술 통계를 대시보드 형태로 제공합니다.

## 🛠 기술 구현 상세

- **Frontend**: Vite + React + Framer Motion + Recharts + Lucide React
- **Data Integration**: `scripts/prepare_web_data.py`를 통해 복잡한 CSV 데이터를 최적화된 JSON 구조로 변환하고 영상 에셋을 자동으로 배포 경로로 복사했습니다.
- **Build**: `npm run build`를 통해 모든 컴포넌트의 정합성을 검증했습니다.

## 🚀 실행 방법

로컬에서 대시보드를 확인하시려면 터미널에서 다음 명령어를 실행해 주세요:

```powershell
cd web
$env:PATH = "C:\Program Files\nodejs;" + $env:PATH
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 시 결과를 확인하실 수 있습니다.

> [!NOTE]
> 본 대시보드는 `v5.7` 데이터를 기준으로 구축되었으며, 향후 파이프라인 업데이트 시 `prepare_web_data.py`를 통해 손쉽게 데이터를 갱신할 수 있습니다.
