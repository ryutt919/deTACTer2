# deTACTer v5.9 Walkthrough (Versioned Copy)

본 문서는 v5.9 파이프라인 실행 결과와 주요 개선 사항을 상세히 기술합니다. (이 문서는 v5.9 전용 히스토리 기록용입니다.)

## 🎯 주요 목표 및 수정 사항

- **TPE 메트릭 변경**: Silhouette Score 대신 **Validation Loss (MSE)** 최소화를 목표로 최적화 수행.
- **데이터 파라미터 고정**: 사용자 요청에 따라 `total_seq_len: 8`, `min_pass_count: 3`으로 고정하여 학습 진행.
- **로깅 강화**: TPE Trial별 상세 정보 및 최종 학습 시 Early Stopping 발생 여부를 기록.
- **애니메이션 자동화**: 클러스터링 결과 파일명 매칭 오류 수정 및 자동 생성 파이프라인 연결.

## 🛠️ 작업 내역 요약

1. **scripts/train_embedding_model.py**: TPE 메트릭을 `val_loss`로 변경하고, v5.9 버전에서 파라미터를 강제 고정하는 로직 추가.
2. **scripts/run_v50_animations.py**: 애니메이션 생성 안정성 확보 및 로깅 개선.
3. **scripts/run_v5_9_pipeline.py**: 통합 파이프라인 구축 및 파일명 변환 로직 보완.
