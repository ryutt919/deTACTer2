# deTACTer v5.5 Disconnected Event & Analysis Restoration Walkthrough

## 사용자 요구사항

- **Disconnected Event (`is_dis`)** 도입: 전후 좌표 불일치 지점을 감지하여 시퀀스 경계로 설정.
- **분석 절차 복원**: v4.5 이후 유실된 팀별 통계 및 시각화 보고서 재생성.
- **데이터 정합성 향상**: 궤적 보정 후 단절을 확인하여 불필요한 단절 최소화.

---

## 구현 및 변경 사항

### 1. 전처리 고도화 ([preprocessing.py](file:///c:/Users/Public/Documents/DIK/deTACTer/scripts/preprocessing.py))

- **`is_dis` 컬럼 추가**: `Prev.End != Curr.Start` (오차 범위 1e-3) 지점을 `is_dis=True`로 마킹.
- **로직 순서 보정**: 궤적 보정(Refine)을 먼저 수행한 후 단절점을 판별하여, 보정 가능한 간격이 단절로 오인되는 것을 방지.
  - 결과: 단절점 감지 건수가 약 189,417건에서 **97,785건**으로 감소 (안정성 향상).

### 2. 시퀀스 추출 고도화 ([sequence_extraction.py](file:///c:/Users/Public/Documents/DIK/deTACTer/scripts/sequence_extraction.py))

- **동적 경계 설정**: 역추적(Backtracking) 중 `is_dis == True`를 만나면 조기에 추적을 중단하고 해당 지점 다음 액션을 시퀀스 시작점으로 설정.
- **결과**: 총 **124개**의 정교한 공격 시퀀스 추출 완료.

### 3. 분석 보고서 복원 ([analyze_sequences.py](file:///c:/Users/Public/Documents/DIK/deTACTer/scripts/analyze_sequences.py))

- `results/anal/v5.5/` 경로에 다음 5종 보고서 생성 완료:
  - `01_team_counts.png`: 팀별 시퀀스 생성 빈도
  - `02_team_success_rate.png`: 팀별 공격 성공률
  - `03_tempo_distance.png`: 공격 템포(속도) 및 이동 거리 분포
  - `04_start_location_heatmap.png`: 공격 시작 위치 밀도
  - `05_action_composition.png`: 패스/드리블 등 액션 구성 비율
