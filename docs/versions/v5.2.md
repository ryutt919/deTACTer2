# v5.2: 맥락 강화 시퀀스 추출

## 업데이트 개요

- **배경**: 이전 버전에서는 공격 시퀀스 추출 시 상대팀의 이벤트(태클, 인터셉트 등)를 완전히 배제하여 전술적 상황 파악에 한계가 있었음.
- **핵심 변경**: 시퀀스 추출 로직을 수정하여 상대팀 이벤트를 포함하되, 시퀀스 길이(9개 액션) 및 불응기(5개 액션) 계산 시에는 공격팀의 액션만을 카운트하도록 개선.

## 주요 성과

1. **전술적 맥락 보존**: 공격 과정 중 발생하는 상대팀의 수비 시도와 이에 따른 공격권 재확보(Recovery) 과정이 데이터에 고스란히 남게 됨.
2. **데이터 정합성**: 시퀀스 길이 제한은 공격팀 기준을 엄격히 준수하여 모델 학습의 안정성을 유지함.
3. **분석 고도화**: 상대팀의 개입 위치와 종류를 함께 분석할 수 있어 더욱 풍부한 전술 패턴 추출 가능.
