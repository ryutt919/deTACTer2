# v5.0 업데이트 내역

## 사용자 요청 사항 및 수정 내용

### 1. VAEP 파이프라인 고도화

- **TPE 최적화 (Optuna)**: `nr_actions` (라벨 예측 범위, 3~7)를 포함한 CatBoost 하이퍼파라미터를 TPE로 최적화했습니다.
- **최고 AUC**: **0.9345** 달성
- **최적 파라미터**:
  - `nr_actions`: 4
  - `n_estimators`: 797
  - `learning_rate`: 0.0508
  - `max_depth`: 9
- **결과 저장**: `data/refined/v5.0/best_params.yaml`

### 2. VAEP 계산

- 최적 파라미터를 사용하여 전체 **504,242 액션**에 대한 VAEP 값을 산출했습니다.
- 평균 VAEP: 0.0012, 최대 VAEP: 1.0111
- **결과 저장**: `data/refined/v5.0/vaep_values.csv`, `vaep_summary.csv`

### 3. 클러스터링 고도화 (이동 흐름 기반 DTW)

- 공의 이동 벡터(dx, dy)를 정규화하여 **전술적 흐름의 유사성**을 기반으로 DTW 클러스터링을 수행했습니다.
- **세분화 완료**: 7개에서 **15개(Agglomerative)** 클러스터로 확장하여 정교한 패턴 식별 가능.

### 4. 분석 노트북 및 도구 (소프트 코딩 적용)

- **`vaep_tpe_analysis.ipynb`**: TPE 최적화 결과 및 **하이퍼파라미터 영향도(AUC 변화)** 분석 추가.
- **`tactical_clustering_analysis.ipynb`**: 클러스터별 패턴 특징 및 **VAEP 위협도 순위** 심층 분석.
- 모든 노트북은 `config.yaml`의 버전을 동적으로 읽어오도록 설계됨.

### 5. 애니메이션 (일괄 생성)

- `run_v50_animations.py`를 통해 모든 클러스터의 대표 샘플 애니메이션(MP4) 일괄 생성.
- **인코딩 안정화**: FFmpeg 라이브러리 호환성 문제를 해결하기 위해 ImageIO 기반의 하이브리드 인코딩 로직 적용.
